# Интерфейс: 25 сентября 2026

- Дневная палитра: [Sage Garden, serafimcloud](https://21st.dev/community/themes/sage-garden).
- Ночная палитра: [baroworks, ahndohun](https://21st.dev/community/themes/baroworks-1783943524832).
- Цвета получены через MCP 21st.dev. Текст дневных основных кнопок затемнён для контраста, границы полей сделаны видимыми.
- Поиск логотипа ITles и отраслевых иконок через тот же MCP не дал подходящего набора. Знак IT/телеметрия оригинальный; пиктограммы категорий — установленный Lucide, без новых зависимостей.
- Слой карты, рельеф и тема сохраняются в `settings` с ключом пользователя; новые таблицы и миграции не нужны. Остальные фильтры пока относятся к текущему экрану.
- Фото доступно только в карточке машины, с проверкой видимости и прав редактирования. В таблицу парка фото не загружается.
- Каталог во вкладке «Масло» использует продукты из действующих регламентов ТО, а не выдуманные складские остатки. Вязкость определяется по обозначению SAE в названии продукта; наличие не подключено.
- Подключение текущего телефона открывает сопряжение в том же браузере/Android WebView; замена существующей привязки требует подтверждения. Сбор данных запускается отдельно пользователем.

Проверки используют изолированные синтетические данные. Обновление веб-интерфейса не означает пересборку ранее опубликованных APK/Windows ZIP или проверку на физических устройствах.
