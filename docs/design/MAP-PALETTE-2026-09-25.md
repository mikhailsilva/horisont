# Карта и организации — 25.09.2026

- Палитра подобрана через MCP 21st.dev: [Sage Garden, serafimcloud](https://21st.dev/community/themes/sage-garden). Не импортируем тему целиком: для организаций один приглушённый `#7c9082`; для ночной карты чёрная основа `#0a0a0a`, нейтральные дороги и спокойные подписи.
- Карточки организаций и текст выровнены по одной вертикали. Иерархия обозначена одной полосой шириной 6/18/30 px внутри карточки, без сдвига строки, разноцветных вложенных полос и заливки всей карточки.
- День/ночь карты сохраняются в настройках пользователя отдельно от темы кабинета. Возврат «Сейчас» есть на карте парка и машины; таймлайн также имеет кнопку «В реальное время», сбрасывающую дату, воспроизведение и курсор.
- 3D-здания подключаются из векторного слоя OpenFreeMap `building` при масштабе от 14. Используем высоты поставщика, не придумываем их. Ночная схема проверена в браузере с программным WebGL2: в выбранном городском фрагменте отрисовано 710 геометрий зданий. Это проверка карты, не телематики или полевого оборудования. Растровые спутник/топокарта не содержат векторных зданий.
- Traccar: проверка доступа без сохранения, личный синтетический API и временный токен для реального суперадминистратора. Ограничения VPS и инструкция: [personal-traccar-demo](../operations/personal-traccar-demo.md).
- Нативные пакеты 0.3.2: Windows ZIP без подписи; Android versionCode 3, debug-подпись. Не проверены на физических устройствах. Debug APK нельзя считать совместимым обновлением старого release APK.
